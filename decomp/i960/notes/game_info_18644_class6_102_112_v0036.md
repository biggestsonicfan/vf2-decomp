# `fa_game_info` `0x18644`: class 6 representative (`0x102<->0x112`)

This note records ROM-backed recovery of the final previously unrepresented instruction-vector class in the enumerated bit-8 plus `{1,2,4}` fighter-state space.

The representative pair is `0x102/0x112` and its reverse orientation. The state values are read from the real `fighter + 0x1a4` fields: `0x102` is bit 8 plus bit 1, while `0x112` is bit 8 plus bits 1 and 4.

The pure-ROM caller-to-task vector is `(219, 224, 216, 221)` for `(countdown=0/mode6=0, countdown=0/mode6=1, countdown=1/mode6=0, countdown=1/mode6=1)`.

The exact pair was admitted only in the existing bilateral gate, bit1-specific gate and final threshold guard. Before instruction-accounting adjustment, CPU architectural state and mutable memory matched the ROM in all 16 isolated probes (two orientations x two call sites x countdown x mode bit 6), and procedure calls/returns were already exact.

First-call accounting was measured independently for both orientations. As with class 5, the second call observes an internally reversed `r7/r8` role relative to the starting physical orientation even though the underlying `fighter+0x1a4` memory is unchanged. The final accounting therefore keeps the measured first-call table and swaps the second-call correction table by the logical state seen inside `0x18644`.

Final isolated validation is 16/16 exact: CPU state, mutable memory, executed instructions, procedure calls and procedure returns all match the pure ROM.

Final chained validation executed `native 0x18644 #1 -> caller ROM -> native 0x18644 #2 -> tail ROM -> 0x10dcc` for both orientations and all four countdown/mode-bit-6 combinations. All eight cases matched the pure ROM exactly. Final instruction totals were `14275975`, `14275980`, `14275972` and `14275977` for the four mode combinations, with `10249/10248` procedure calls/returns in every case.

Validated functional recovery commit: `b77022b7a854cad3d401ffa4f5c2193685812486`.

With this representative recovered, all nine instruction-vector classes discovered by the 256-case enumerator now have at least one ROM-validated native representative. This does not imply that every one of the 64 state pairs has been individually admitted; rows still marked `recovered_exact=no` remain fail-closed unless separately validated.
