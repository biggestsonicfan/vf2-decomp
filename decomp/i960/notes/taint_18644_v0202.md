# Dynamic taint for 0x18644 corridor v0202

## Goal
Provide sideband evidence for branch dependencies (AGENTS.md: recommended
next work #3) without mutating architectural CPU state. Desired output:
```
branch 0x00018698 depends on:
  fighter0 + 0x1a4 bit 6
  fighter0 + 0x5b6
```

## Tool
`tools/python/taint.py` — streaming, dependency-light (std lib + ROM via
`vf2i960 disasm`). Keeps taint metadata outside CPU/machine state, never
decides hardware behavior.

Inputs:
* `--rom-dir roms/vf2`
* `--scenario out/state8-positive.json` (bases fighter0=0x00510980 / fighter1=0x00512980)
* `--trace out/state8-case-mnem.jsonl` (vf2probe --trace --memory-trace with mnemonic)
* `--window 0x2000` (fighter_candidate.h window)

Implementation covers the operations seen in the target corridor:
loads (ld/ldob/ldis/ldl/ldt/ldq/lda), moves (mov/movl/movt/movq),
bitwise (and/andnot/notand/or/ornot/notor/xor/xnor/nor/nand/clrbit/setbit/alterbit/notbit/not),
shifts (shlo/shli/shro/shri/rotate/shrdi), add/sub (addo/addi/subo/subi/addc/subc/addr/subr/mulr/divr/mulo/muli/remo/remi/modi/divo/divi),
compares (cmpo/cmpi/cmpor/cmpr/chkbit/scanbit/spanbit/concmpo/concmpi) and
conditional branches (bbc/bbs/be/bne/bl/ble/bg/bge/bo/bno/cmpob* etc).

Taint is per-register (`r0..r31`, `g0..g15` normalized to `r16..r31`, `fp`)
as `Set[tag]` where tag is `fighterX + 0xOFF` when a memory read address
falls in the fighter window (via `tag_for_address`). Stores are sinks.
After a compare, `condition_taint` holds the union; a following conditional
branch depends on `condition_taint ∪ operand taints`. Bit-test branches
`bbc/bbs k,r` annotate tags with ` bit k`.

Disassembly is fetched per executed IP via `vf2i960 disasm roms/vf2 <ip> 1`
(avoid bulk decode failures on data regions like 0x000185d0). Steps are
sorted by absolute `step` and pending memory accesses are correlated by
that step (same contract as `frontier.py` and `model2a_observer.c`).

## Measured evidence
Run on the single-trace `out/state8-case-mnem.jsonl`
(66/2 flags, `fighter0_flags=0x42`):
```
python tools/python/taint.py --rom-dir roms/vf2 \
  --scenario out/state8-positive.json \
  --trace out/state8-case-mnem.jsonl --vf2i960 build/Debug/vf2i960.exe
```
Excerpt (full run ≈ 25 branches):
```
branch 0x000186c0 depends on:
  fighter0 + 0x0000 bit 4
  fighter1 + 0x01a4 bit 4
  fighter1 + 0x0844 bit 4
  ; bbc 4, r7, 0x000186d4
branch 0x000186d4 depends on:
  fighter0 + 0x01a4 bit 4
  ; bbc 4, r8, 0x00018728
branch 0x00018748 depends on:
  fighter0 + 0x0000 bit 15
  fighter1 + 0x05b4 bit 15
  ; bbc 15, r4, 0x00018750
...
branch 0x000189ec depends on:
  fighter0 + 0x0000 bit 6
  fighter1 + 0x0844 bit 6
  ; bbc 6, r15, 0x000189f8
```
The fighter-window hits correspond to stable offsets in
`fighter_candidate.h` (`0x01a4`, `0x05b4`, `0x0844`, `0x0000`, etc.).
Non-fighter registers (e.g., `r9` holding interpolated position) show
as `fighter0 + 0x01f4` / `0x01fc` flowing through `ld → st (g11)[g12] → ld`.

## Relation to frontier
`frontier.py` already ranks edges by `mem_reads/mem_writes/call_hits`.
Taint now explains *why* a branch is taken, enabling compact rule inference
instead of mask tables. Next step is to feed branch preconditions into Z3
(32-bit bitvectors) to generate witnesses or prove equivalence of candidate
predicates, per AGENTS.md guidance (use Z3 only after concrete measured question).

## Limitations
* Intraprocedural only (single trace, no inter-procedural call taint).
* No floating-point taint (not needed for this corridor).
* For fused `cmpibg` etc., dependency is approximated as union of both regs.
* Validated on the 212-step trace (88 memory accesses) only; larger corpora
  should re-run `trace_case.py` + `taint.py --json` for aggregation.
