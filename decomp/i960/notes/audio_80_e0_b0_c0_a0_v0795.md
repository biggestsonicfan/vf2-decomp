## e0 stale + negated index + 0x1356 tail

Kept formula (command|payload<<7, switch-correct). Fixes:
- stale word: d0.upper = ((payload&0x7f)<<7)&0xff00 rides into
  BOTH stored words, negated on the even path.
- index is POST-neg low byte (0xFF on zero-normalize). Note: the
  even arm is unreachable for E0-class (command&0x7f bit5 always
  set => transformed always odd); code mirrors ROM structure,
  untestable via public API, documented.
- tail 0x1356 per channel<9 match: slide = sext16(W + sext16(
  voice[10]+desc[5..6])); T1 = 0x602676[(v3&0xf)] + 2*slide ->
  SCSP+0x10 = (((v3&0xf0)<<7)+word)&0x7bff; T2 = 0x60c726[
  (v3&0xf0)>>2] + (((v3&0xf)<<5)&0xff, byte-wrap!) + 2*slide ->
  ram[0x601a]. Residue audit in master note; d4 dropped (unused).
- channel >= 9 early return stands (benign B0-fallthrough proven
  via 16 zero table-bytes); now with a matching-voice fixture
  proving the tail stays off.
- Handler 0x12b4 -> 0x12b6.
Fixtures: stale-odd, tail (hand-computed 0x2105/0x2234/0xABCD,
matched first run), >=9 with voice. Gates: stale-drop, tail-skip,
early-return-removal. Neg-index: uncoverable by routing (noted).
