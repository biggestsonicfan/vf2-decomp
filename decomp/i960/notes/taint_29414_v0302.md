# v0302: taint medido do corredor `fa_player` `0x29414`

## Resultado

`tools/python/taint.py` nos traces v0297 (types 6/8/10, bit19 clear/set,
path A `11..20` e path B `>20`) produz a mesma dependência:

```text
branch 0x0002949c depends on:
  fighter0 + 0x01a4 bit 19
  ; bbc 19, r14, 0x00029538
```

Isso confirma a hipótese da campanha v0293 (item de taint aberto).

## Limitação conhecida

Os compares de janela em `0x294a4` / `0x294a8` **não** herdam taint de
`+0x01aa` neste heurístico: a carga halfword (`ldis`) não propaga para o
registrador usado no `cmpobl`/`cmpobge`. A janela `+0x1aa` segue
evidenciada por:

- memory-trace (offset relativo a g7 `0x00510980`);
- recuperação C v0297 (`cmpobl 20,r12` = `r12 > 20` unsigned).

Não tratar “sem taint” como “sem dependência”.

## Reprodução

```sh
python tools/python/taint.py --rom-dir roms/vf2 \
  --vf2i960 build/Debug/vf2i960.exe \
  --scenario out/v302/29414-g7.json \
  --trace out/v297/trace-t6-b19-aa11.jsonl \
  --window 0x2000 --json out/v302/taint-29414-pathA.json
```

Mesmo comando com `trace-t6-b19-aa21.jsonl` (path B),
`trace-t6-b19-aa10.jsonl` (float) e `trace-t8-b19-aa11.jsonl` (type 8).
