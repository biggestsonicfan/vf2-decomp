# fa_game_info 0x18644 high state flags
Controlled ROM probes recover the `0x18978..0x189a4` high-state flag tail. Bits 26..29 (`0x3c000000`) use the unsigned `+0x84e` progress versus `+0x1aa` limit gate; entering that branch costs three instructions and the OR costs one more when progress >= limit. Bits 30..31 (`0xc0000000`) are always accumulated and add no conditional cost. From the real sixth-dispatch snapshot the baseline was 677 instructions/12 calls to `0x16500`; bit26 measured 681/12, bit30 677/12, and bit26+30 681/12. `fighter0+0x5b8` became respectively `0x00000002`, `0x04000002`, `0x40000002`, and `0x44000002`.
