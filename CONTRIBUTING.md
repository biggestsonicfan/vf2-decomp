# Contributing

Start by reading:

- `docs/LEGAL.md`;
- `docs/DECOMP_GUIDE.md`;
- `docs/ARCHITECTURE.md`.

Keep pull requests focused on one function, structure, tool or documented
hardware behavior. Every recovered function should include the evidence used
to identify it and, when possible, a deterministic comparison against original
behavior.

Never upload ROMs, reconstructed binary regions or extracted proprietary
assets.
