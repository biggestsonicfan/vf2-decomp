# vf2-decomp

Clean-room reconstruction and tooling for Virtua Fighter 2 Version 2.1 (Sega Model 2A / Intel i960).

For the ROM-backed `fa_game_info` `0x18644` recovery workflow, reusable differential tools live under `decomp/i960/tools/`. Start with `decomp/i960/tools/README.md` and use `validate_game_info_pair.py` / `validate_game_info_matrix.py` instead of ad-hoc inline Python.
